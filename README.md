# 心靈連結之旅

一款從輕鬆破冰開始，逐步進入自我理解、人際關係與深度對話的線上牌卡遊戲。

## 立即遊玩

👉 [開啟心靈連結之旅](https://ian32253188.github.io/soul-dialogue-game/)

不需要安裝程式，使用手機、平板或電腦瀏覽器即可遊玩。

## 遊戲方式

1. 開啟遊戲網址。
2. 在「選擇要加入的卡組」勾選想使用的牌組；可以複選。
3. 如果需要輪流抽牌，在「參與玩家設定」輸入名字並按「新增」。不新增玩家時，也可以使用自由討論模式。
4. 按「隨機抽取下一張卡」。
5. 點擊卡片翻面，閱讀題目並開始分享。
6. 分享完成後，繼續抽取下一張卡；下方會保留本次遊戲的抽取歷史。

## 四種牌組

- **暖身破冰**：簡單、有趣、適合讓大家熟悉彼此。
- **一星連結 ⭐**：從生活偏好、日常經驗與輕度自我分享開始。
- **二星連結 ⭐⭐**：探索個性、價值觀、情緒反應與關係模式。
- **三星連結 ⭐⭐⭐**：進入人生選擇、家庭、失落、脆弱與深度自我理解。

建議依照現場熟悉程度與氣氛選擇牌組，不一定要從低星等開始。牌卡目前會在勾選的牌組中隨機抽取。

## 自訂牌卡

在「新增自訂牌卡」區域輸入題目，選擇要加入的牌組，再按「新增到牌組」即可。

自訂牌卡會儲存在目前瀏覽器的 `localStorage` 中，因此：

- 同一台裝置、同一個瀏覽器重新開啟後仍會保留。
- 不會同步到其他人的裝置。
- 清除瀏覽器網站資料後可能會消失。
- 點擊「重置全部卡組」只會重建抽牌池，不會刪除自訂牌卡。

## 互動與安全提醒

- 每個人都可以選擇跳過不想回答的題目。
- 分享內容應受到在場成員尊重，不要在未取得同意時錄音、錄影或轉傳。
- 涉及拍照、上傳社群或肢體互動的題目，請先確認所有參與者都同意。
- 深度題目可能引發情緒；若有人感到不舒服，可以暫停、換題或休息。

## 專案資訊

這是一個純前端靜態網站，不需要後端或資料庫。牌卡的唯一來源是 [cards.md](cards.md)，網頁程式會在編譯時自動讀取它並產生部署用的 `dist/index.html`。

### 修改或新增牌卡

1. 編輯 [cards.md](cards.md)。
2. 在對應的星等標題下新增、刪除或調整編號題目。
3. 推送到 `master` 分支。
4. GitHub Actions 會自動檢查格式、檢查完全重複題目、編譯網站並部署 GitHub Pages。

本機也可以先執行：

```bash
npm run build
```

編譯器會接受不同數量的題目，但每個牌組至少需要一題，且所有題目不可完全重複。題目順序就是該牌組的固定順序；網站實際抽牌仍會依目前功能隨機抽取。

本專案使用 Tailwind CSS CDN 與 Google Fonts，因此首次開啟時需要網路連線才能完整載入視覺樣式。
