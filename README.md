# 心靈連結之旅

一款從輕鬆破冰開始，逐步進入自我理解、人際關係與深度對話的線上牌卡遊戲。

## 立即遊玩

👉 [開啟心靈連結之旅](https://ian32253188.github.io/soul-dialogue-game/)

不需要安裝程式，使用手機、平板或電腦瀏覽器即可遊玩。

## 遊戲方式

1. 開啟遊戲網址。
2. 在「選擇要加入的卡組」勾選想使用的牌組；可以複選。
3. 如果需要輪流抽牌，在「參與玩家設定」輸入名字並按「新增」。不新增玩家時，也可以使用自由討論模式。
4. 按「隨機抽取下一張卡」。
5. 點擊卡片翻面，閱讀題目並開始分享。
6. 分享完成後，繼續抽取下一張卡；下方會保留本次遊戲的抽取歷史。

## 四種牌組

- **暖身破冰**：簡單、有趣、適合讓大家熟悉彼此。
- **一星連結 ⭐**：從生活偏好、日常經驗與輕度自我分享開始。
- **二星連結 ⭐⭐**：探索個性、價值觀、情緒反應與關係模式。
- **三星連結 ⭐⭐⭐**：進入人生選擇、家庭、失落、脆弱與深度自我理解。

建議依照現場熟悉程度與氣氛選擇牌組，不一定要從低星等開始。牌卡目前會在勾選的牌組中隨機抽取。

## 自訂牌卡

在「新增自訂牌卡」區域輸入題目，選擇要加入的牌組，再按「新增到牌組」即可。

自訂牌卡會儲存在目前瀏覽器的 `localStorage` 中，因此：

- 同一台裝置、同一個瀏覽器重新開啟後仍會保留。
- 不會同步到其他人的裝置。
- 清除瀏覽器網站資料後可能會消失。
- 點擊「重置全部卡組」只會重建抽牌池，不會刪除自訂牌卡。

## 互動與安全提醒

- 每個人都可以選擇跳過不想回答的題目。
- 分享內容應受到在場成員尊重，不要在未取得同意時錄音、錄影或轉傳。
- 涉及拍照、上傳社群或肢體互動的題目，請先確認所有參與者都同意。
- 深度題目可能引發情緒；若有人感到不舒服，可以暫停、換題或休息。

## 專案資訊

這是一個純前端靜態網站，不需要後端或資料庫。牌卡的唯一來源是 [cards.md](cards.md)，網頁程式會在編譯時自動讀取它並產生部署用的 `dist/index.html`。

### 修改或新增牌卡

之後不需要直接修改 `index.html`，只要編輯 [cards.md](cards.md) 即可。

#### 在電腦上修改

1. 開啟專案中的 `cards.md`。
2. 找到要修改的牌組：`暖身破冰`、`一星連結`、`二星連結` 或 `三星連結`。
3. 修改原本題目的文字，或在該區塊最後新增一行編號題目。
4. 儲存檔案。
5. 若要先在本機檢查，於專案資料夾執行：

   ```bash
   npm run build
   ```

6. 確認編譯成功後，將 `cards.md` 的變更提交並推送到 `master`。

#### 直接在 GitHub 網頁上修改

1. 開啟 GitHub 專案頁面的 [cards.md](https://github.com/ian32253188/soul-dialogue-game/blob/master/cards.md)。
2. 點擊右上角鉛筆圖示（Edit this file）。
3. 修改或新增題目。
4. 在頁面下方填寫變更說明，選擇建立分支或直接提交到 `master`。
5. GitHub Actions 會自動執行檢查、編譯與部署。

#### Markdown 格式

每張牌使用一行，前面加上編號與句點；編號只是閱讀用，編譯器會依檔案順序重新建立牌組位置。

```md
## 二星連結 ⭐⭐

1. 原本的題目可以直接修改。
2. 這是新增的題目。
```

請保留四個牌組標題，並注意：

- 每個牌組至少要有一題。
- 所有牌卡文字不可完全重複。
- 題目不要跨多行；一題放在一行最穩定。
- 可以調整題目順序，網站會依新順序建立該牌組的固定位置。
- 可以增加或減少題目，不必維持 10／20／20／20 的數量。

#### 自動部署流程

推送 `cards.md` 後，`.github/workflows/deploy-pages.yml` 會依序：

1. 讀取 `cards.md`。
2. 檢查牌組標題、空白題目與完全重複題目。
3. 產生 `dist/index.html`。
4. 將 `dist` 部署到 GitHub Pages。

只有編譯成功才會部署；如果格式或重複檢查失敗，舊的線上版本會保留不變。可以到 GitHub 專案的 **Actions** 頁面查看錯誤行數。

本機也可以先執行：

```bash
npm run build
```

編譯成功後，產生的網站檔案位於 `dist/index.html`；牌卡來源仍然只有 `cards.md`，不要手動修改 `dist/index.html`。題目順序就是該牌組的固定順序；網站實際抽牌仍會依目前功能隨機抽取。

本專案使用 Tailwind CSS CDN 與 Google Fonts，因此首次開啟時需要網路連線才能完整載入視覺樣式。
